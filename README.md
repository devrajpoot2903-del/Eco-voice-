# EcoVoice

EcoVoice is a voice-first task management application that enables users to create, manage, update, and organize tasks using natural voice commands. It combines speech recognition, intelligent command parsing, voice feedback, and AI-powered assistance to provide a hands-free productivity experience.

---

## Features

### Voice Control

* Create tasks using voice commands
* Delete tasks using voice commands
* Complete and uncomplete tasks
* Pin and unpin important tasks
* Mark tasks with priority levels
* Search tasks through voice

### Task Management

* Create, update, and delete tasks
* Task completion tracking
* Priority management
* Pinned tasks support
* Undo functionality
* Task history support

### AI Features

* Gemini AI integration
* Chat Mode
* Voice responses
* Fallback AI assistance

### Accessibility

* Voice-first interaction
* Manual text input support
* Speech feedback system
