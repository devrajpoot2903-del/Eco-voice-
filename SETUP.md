# EcoVoice Setup Guide

## Prerequisites

Install:

* Node.js
* npm

---

## Clone Repository

```bash
git clone https://github.com/devrajpoot2903-del/Eco-voice-.git
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment Variables

Create a .env file in the project root.

```env
VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

---

## Start Development Server

```bash
npm run dev
```

---

## Build Project

```bash
npm run build
```

---

## Technologies Used

* React
* Vite
* JavaScript
* Web Speech API
* Gemini 2.5 Flash API

---

## Notes

* A valid Gemini API key is required for AI chat functionality.
* Voice recognition depends on browser support.
* Google Chrome is recommended for best results.
